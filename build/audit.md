# Auditoria

O `doccheck` prova que tudo o que os docs **nomeiam** existe no código. Este
arquivo cobre o resto: o que o código já construído faz de errado, o que a prosa
**exige** e nenhum teste prova, e o que os docs diziam e o código desmentia. Uma
linha por achado da revisão de 2026-11-07 (oito passadas sobre core, casca,
coletor, front e a referência do iTero), cada um conferido à mão no código,
arquivo e linha.

**Estados:**
- **OPEN:** não corrigido. A Prova diz o teste que falharia antes da correção,
  quando ele já se sabe; senão, "—".
- **BUILT:** corrigido. A Prova cita o T-ID do [13](../docs/arquitetura/13-testes.md)
  que falha com a linha antiga, e o `doccheck` confere que o T-ID está feito no
  catálogo.
- **DEFERRED:** fica para depois. A Prova diz o motivo, e o mesmo motivo está em
  `tools/doccheck/deferred.txt`.
- **DOC:** o código está certo e o doc estava errado; o doc foi corrigido. A
  Prova diz a seção editada.

**Como o `doccheck` lê:** toda linha que começa com `| A1 |`, `| B1 |`, `| D1 |`
ou `| P1 |` é uma linha da auditoria. O estado é a primeira célula igual a OPEN,
BUILT, DEFERRED ou DOC; a prova é a última célula. Uma linha BUILT sem T-ID, ou
DOC e DEFERRED sem prova, vira aviso. `npm run doccheck -- -closed` falha com
qualquer OPEN fora da tabela P. Para mudar uma linha:
`python3 tools/dev/audit_set.py ID ESTADO PROVA`. Nenhuma célula leva barra
vertical.

**Nada foi corrigido nesta passada:** toda linha A e B está OPEN, e a Fase é "—"
até alguém planejar. As linhas D são os docs que esta revisão corrigiu.

Referências da coluna Doc §: `arq` é `docs/arquitetura`, `front` é
`docs/frontend`, `prod` é `docs/produto`, `req` são os requisitos, `ref` é
`docs/referencia/itero`. Os IDs A1, A2, A3 e B1 a B6 são fixos: outros arquivos já
os citam.

## A — Defeitos no que já está construído

Em ordem de gravidade, como no [frontend 07](../docs/frontend/07-lacunas-da-casca.md):
**grave** faz a tela mentir, contraria uma regra da Riot, dá conselho errado ou
perde dado; **média** mostra dado velho ou incompleto num caso comum, ou deixa
uma prova sem conseguir falhar; **baixa** é duplicação, código morto ou folga que
ainda não errou. O número não segue a ordem: A1 a A3 já eram citados.
